How Request Routing Works (End-to-End)
1
Static Frontend Request: Browser navigates to /preview/alice-test/. ALB forwards to serveFrontend Lambda, which streams preview/alice-test/index.html from S3.
2
Preview Backend API Request: Frontend makes API call to /api/random with HTTP header X-Preview-Env: alice-test. ALB evaluates Listener Rules (Priority 10..89) and forwards to Alice's target group (port 3000).
3
Baseline Backend API Request: Frontend or external client calls /api/random without header. ALB falls back to Priority 100 Rule, forwarding to Baseline Target Group.
4
Kafka Isolation: Containers read KAFKA_TOPIC_PREFIX. Microservice messages are partitioned onto preview-alice-test-events without polluting production streams.
